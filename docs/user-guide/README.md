# User Guide

The User Guide is the entry point for people using Job Radar. It will contain task-oriented instructions, product concepts, and troubleshooting that can be understood without repository or issue history.

Job Radar is still an early prototype. For the current product overview and available capabilities, start with the repository [README](../../README.md). The core user concepts are:

- **Source** — a saved place from which job postings can be discovered.
- **Search Request** — saved search intent, including terms, exclusions, locations, and selected Sources.
- **Search Run** — one execution of a Search Request with per-Source outcomes.
- **Job Posting** — a normalized result that can be observed through one or more Sources.

Detailed task guides will be added here as those product surfaces stabilize. Product requirements and implementation details belong in the [Product](../product/README.md) and [Development](../development/README.md) areas rather than in user instructions.
